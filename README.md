## 💥 ПОЧЕМУ ЭТОТ БОТ

### 😱 Проблема

**Вы теряете заказы, потому что:**
- ❌ Менеджер **не отвечает ночью** — клиент ушёл к конкурентам
- ❌ Заказы **теряются** в личке Telegram — хаос
- ❌ Клиент **не знает**, какие товары есть — надо каждый раз отвечать
- ❌ **Нет статистики** — непонятно, что продаётся

### ✅ Решение — этот бот

- ✅ **Принимает заказы 24/7** — даже когда вы спите
- ✅ **Каталог с фото** — клиент сам выбирает
- ✅ **Оплата картой** через Telegram Payments — **деньги сразу на счёт**
- ✅ **Уведомления с ссылкой на клиента** — пишите ему в 1 клик
- ✅ **Админ-панель** — статистика, заказы, товары — всё под контролем

**Итог:** клиент **оформляет заказ за 1 минуту** — вы **получаете оплату** и **уведомление**.

## ⚙️ БЫСТРЫЙ СТАРТ — 5 МИНУТ

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Sisyapisa/tg-shop-bot.git
cd tg-shop-bot
```

### 2. Создай виртуальное окружение

```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / Mac:
source venv/bin/activate
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Создай `.env`

```env
BOT_TOKEN=твой_токен_от_BotFather
ADMIN_ID=твой_telegram_id
PROVIDER_TOKEN=токен_от_BotFather_для_оплаты
```

**Где взять:**
- `BOT_TOKEN` — [@BotFather](https://t.me/BotFather) → `/newbot`
- `ADMIN_ID` — [@userinfobot](https://t.me/userinfobot)
- `PROVIDER_TOKEN` — [@BotFather](https://t.me/BotFather) → **Payments** → **ЮKassa (TEST)** → **Get provider token**

### 5. Запусти

```bash
python main.py
```

**Готово! Бот работает.** Заходите в Telegram → `/start` → `/admin` → добавляйте товары.
